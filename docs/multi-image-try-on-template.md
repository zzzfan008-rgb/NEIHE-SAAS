## 2026-09-22 模板优化

- 新模板默认 Gemini 3.1 Flash Image、2K，Pro 继续可手动选择。基于用户已验证 Flash 能生成的反馈选择默认模型，不承诺 Pro 的 OTHER 可通过提示词修复。
- TiAngel 关闭时，姿势图同时约束动作、视角与取景，场景只提供环境与光照；开启时按目标模型编译 TiAngel 指令，保留肢体动作与接触关系，允许相机改变画面投影。两种模式都不新增中间生图步骤。
- 普通与简化提示词均保留人物自然肤质、发丝、面料组织、印花、缝线、五金要求；只有实际分组后才描述拼图。简化仅精简冗余说明。
- UI 与模板说明统一为 Pro 14 张阈值；仅多图模式去除 Flash 的“旧配置兼容”标签。OTHER 显示服务方未提供具体触发原因，不推断哪张图或具体规则。
- 本次不提高输出默认尺寸、不放宽共享图片压缩预算，不自动切换模型或重发审核拒绝请求。

## 参考图契约

- 新模式仅作用于 `workflowStage=scene-stabilize`、`sceneInputMode=multi-reference-edit`，旧模式不变。
- 姿势、人物、场景各一张，固定为参数 1、2、3；主穿搭另需一张。
- Gemini 3 Pro Image：有效输入不超过正式接口的 14 张容量时仅排序、逐张直接传入；超过时优先合并配饰，再合并鞋袜，仍超限才合并服装和细节。前三张永不拼接。
- 空节点和未连接节点不计入有效参考图。新模式最多接收 20 张原始素材；其他模型继续遵守各自请求限制，不套用 Pro 超额拼接策略。
- 拼图在服务器本地完成，不调用图像模型。每格最大 1024 像素，保持长宽比、完整内容和方向；高体积拼图经过既有 Provider 大小门禁压缩，不能保证与原图逐像素等同。
- 前端编号与服务器分组共用规划器；提示词逐图、逐格标明用途。记录保存全部原始素材及对应的参数编号，不把临时大拼图写进项目文档。
- 仅连接新模式的姿势输入不自动反推姿势文字，也不强制生成人物底图。
- 局部修改没有自动接入成片，必须由用户选择具体图片、连线、保存蒙版后单独发起。沿用现有蒙版范围外保护逻辑。
