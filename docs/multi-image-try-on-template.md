# 多图编辑换装+修改

## 范围

从当前保存的「一键换装 - 副本」（项目 `9gXK9ktmYg`）独立复制，源项目未写入。
模板定义：`templates/multi-image-try-on.workflow.json`。它是新建模板 POST 请求的完整正文，不是对旧模板的更新。

新流程：原始多图编辑换装 → 用户选择成片后按需蒙版局部修改。
删除副本中的前置人物合成和整图服装精修；保留原副本的 3D 拍摄参数。模板不携带原项目私有照片、历史生成结果或蒙版。

## 参考图契约

- 新模式仅作用于 `workflowStage=scene-stabilize`、`sceneInputMode=multi-reference-edit`，旧模式不变。
- 姿势、人物、场景各一张，固定为参数 1、2、3；主穿搭另需一张。
- Gemini 3 Pro Image：有效输入不超过 6 张时仅排序、直接传入；超过时优先合并配饰，再合并鞋袜，仍超限才合并服装和细节。前三张永不拼接。
- 空节点和未连接节点不计入有效参考图。新模式最多接收 20 张原始素材；其他模型继续遵守原有请求限制，不套用 Pro 六图策略。
- 拼图在服务器本地完成，不调用图像模型。每格最大 1024 像素，保持长宽比、完整内容和方向；高体积拼图经过既有 Provider 大小门禁压缩，不能保证与原图逐像素等同。
- 前端编号与服务器分组共用规划器；提示词逐图、逐格标明用途。记录保存全部原始素材及对应的参数编号，不把临时大拼图写进项目文档。
- 仅连接新模式的姿势输入不自动反推姿势文字，也不强制生成人物底图。
- 局部修改没有自动接入成片，必须由用户选择具体图片、连线、保存蒙版后单独发起。沿用现有蒙版范围外保护逻辑。
