# 服装设计师工作流PRD

- 产品：Garment Canvas
- 版本：v0.1
- 日期：2026-09-18
- 最近更新：2026-09-19
- 状态：需求讨论归档；核心方向与圈选文字修订方式已确认，详细交互与技术实现待验证。
- 依据：本次用户需求讨论。本文描述目标产品行为，不代表相关能力已实现或已达到质量指标。

## 1. 背景与目标

设计师通常先画出初步黑白灰草图，再从意向参考图中提取灵感，融合自己的设计想法，反复调整服装廓形、比例和结构。设计意图往往较抽象，无法在第一次输入时完整表达，需要通过看到候选结果、指出差异、继续修改逐步明确。

产品目标是辅助设计师将抽象构思逐步具象化。线稿阶段以黑白灰确定廓形、比例、结构和拼接分区；“草图→效果图”阶段依据定稿线稿及区域材料信息，表现厚薄、软硬、垂坠等材料特性，生成基础效果图；颜色与纹理由后续“面料配色替换”节点控制。

用户提出的“版型正确率达到 98% 以上”指线稿对设计师预期的廓形、比例和结构的还原程度，不包含实际打版尺寸、纸样精度或生产工艺准确性。98% 作为设计师认可的目标，不能用模型自评分宣称已经达标；正式量化方法仍需通过设计师案例共同确定。

## 2. 用户与使用范围

- 主要用户：通过草图和参考图进行服装创作的设计师。
- 交付形式：新建一套面向服装设计师的工作流模板，与现有模板并存；不是替换现有模板或迁移已有项目。
- 门槛范围：本文的线稿定稿确认要求适用于新模板的设计流程，不扩展为全产品所有“草图→效果图”操作的统一限制。
- 使用平台：桌面网页，遵循项目最低 1024 CSS px，以及 1280、1440px 主要验收宽度。
- 核心场景：初次设计融合、针对选定线稿的多轮局部修订、线稿定稿后生成效果图。
- 不纳入本版：移动端、工业制版、尺寸精度保证、自动生成可生产纸样、无人确认的自动定稿。

## 3. 目标工作流

初步草图＋意向参考图＋设计想法 → 明确融合意图 → 黑白灰候选线稿 → 圈选与文字反馈 → 多轮修订 → 设计师确认线稿定稿 → 草图转基础效果图 → 设计师确认基础效果图 → 面料配色替换（颜色与纹理）。AI 改款涉及结构变化时，沿用下述回流规则。

前半段是可反复迭代的设计过程。设计师调整想法后，下一轮以最新确认的意图和选定线稿为依据。生成成功不等于设计已通过确认。

### 阶段职责汇总

| 阶段 | 本阶段负责 | 不在本阶段决定 | 进入下一阶段的条件 |
| --- | --- | --- | --- |
| 黑白灰线稿 | 廓形、比例、结构、关键细节与拼接分区；参考融合及圈选修订 | 实际材料、最终颜色与纹理 | 设计师确认具体视图及线稿版本定稿 |
| 基础效果图 | 在节点内提供区域材料，以中性灰阶、无人物立体展示表现厚薄、软硬与垂坠 | 最终颜色、纹理与模特上身 | 设计师确认选定基础效果图的廓形、结构与材料垂坠 |
| 面料配色替换 | 复用分区，按图片／文字要求调整颜色与纹理 | 未经允许改变廓形、结构或未指定区域 | 后续交付与最终确认方式尚待明确，不新增自动定稿规则 |

上述为产品职责划分，不表示相关模型能力或技术门槛已经实现。各阶段材料特性与结构保持的实际效果仍需验证。

### 3.1 初次融合

若设计师已满意自己上传的线稿，可跳过 AI 优化与候选生成，直接确认该具体线稿版本定稿并进入“草图→效果图”节点，再提供对应区域的实际材料。不强制先生成候选。

1. 输入初步草图作为底稿。
2. 添加意向参考图，为每张图说明希望借鉴的元素及不希望带入的内容。
3. 填写自己的设计想法，以及需要保留和允许修改的部分。
4. 系统将输入组织为可理解、可编辑的设计说明；存在实质歧义时请设计师澄清。
5. 默认生成 2 张黑白灰候选线稿，可切换为 1 张，由设计师查看并选择后续修订底稿。

参考图的作用不能与底稿混淆。例如：保留底稿的轮廓和衣长，借鉴参考图 A 的袖口结构，借鉴参考图 B 的斜向分割线；不得因此默认复制参考图的领口、装饰和配色。

### 3.2 逐轮修订

1. 打开选定线稿，进入标注修改工作区。
2. 在图上自由圈选需要调整的部位。
3. 为圈选填写文字要求，形成一条明确的“区域＋要求”标注。
4. 可继续添加其他标注；每条标注可单独编辑或删除。
5. 必要时为某条标注关联参考图，并说明借鉴内容；可在参考图上圈出具体借鉴部位，也可直接使用整张参考图配文字说明。
6. 将本轮提交的全部标注一起处理，默认生成 2 张候选线稿，可切换为 1 张，每张均以完成全部修改要求为目标；不是按标注数量分别生成。保留原版及标注，要求冲突时先澄清再生成。
7. 对比候选与原版，决定是否采用；采用后以该版本继续标注。

示例：① 袖口收窄，保持袖长，参考图 A 的袖口结构；② 衣长缩短，保留下摆弧度。

## 4. 核心产品要求

### 4.1 输入角色与设计意图

- 正背面处理原则（已确认）：设计师草稿中会包含正面及背面图。第一版正面、背面按独立线稿分别编辑和确认，不承诺自动同步结构变化；一面修改或定稿不能使另一面自动被视为同步完成或已确认。多视图联动留待后续验证。
- 同图正背面输入（已确认）：支持整张上传包含正面、背面的草稿，无需设计师提前拆图；上传后由设计师圈定并标记“正面／背面”，选择对应视图进行修改与确认。视图区分的圈定不同于指定局部修改的标注；具体提取与展示方式仍需设计验证。
- 明确区分底稿、意向参考图、修改要求和保持要求。
- 参考图数量规则（已确认）：第一版每轮最多使用 3 张参考图，不含底稿；初次融合与局部修订均无需用满，局部修订可不带参考图。此上限是产品需求，实际模型承载能力仍需验证。
- 接受自然语言和不完整的设计表达，不要求用户预先编写专业提示词。
- 对“更利落但保留宽松感”等抽象要求，系统可提出具体修改理解，供设计师修正。
- 不能将推测直接视为用户确认的设计决定。
- 要求增量更新（已确认）：以已有设计与要求为基础理解新指令；设计师明确修改某项时，直接更新该项旧要求，其他要求继续有效，无需先解除旧约束。例如旧要求为“保持衣长”，新指令为“缩短衣长”，则更新衣长要求，领口、袖型等未涉及要求继续保留。此类明确更新不属于需要再次确认的冲突；新意图含糊或同轮要求确有矛盾且无法确定意图时才澄清，既定圈外结构联动确认仍适用。
- 保持要求来源（已确认）：设计师可直接填写保持要求；系统也可根据底稿与修改要求提出建议，但系统建议须经设计师确认后，才作为跨轮保留的保持要求。未确认建议不能自动成为设计约束，也不因此要求每轮重复确认已经有效的保持要求；未指定修改部分沿用底稿的既定原则仍然适用。
- 修改摘要确认规则（已确认）：要求清晰时支持直接生成，系统整理的修改摘要可查看但不强制逐轮确认；仅在要求冲突、借鉴范围存在实质歧义或涉及圈外结构联动时暂停生成，请设计师澄清或确认。小范围线条衔接沿用无需额外确认的规则。
- 输入解释原则（已确认）：明确的文字修改要求优先；未明确要求修改的部分沿用底稿；意向参考图只提供指定借鉴元素，不能自动覆盖底稿的其他设计。
- 当借鉴范围存在影响设计结构的歧义时，先确认再生成。例如底稿为落肩袖、参考图为插肩袖，而要求仅为“参考这张图的袖子”，应确认是只借鉴袖子形状还是连肩袖结构一起改变。
- 上述优先级不用于替用户解决相互矛盾的文字要求；冲突未澄清前不能将模型选择当作用户决定。
- 参考图圈选规则（已确认）：第一版支持在参考图上圈出具体借鉴部位，并关联到底稿的修改标注，配合文字说明借鉴内容与保持要求；圈选为可选操作，不圈选时仍可使用整张参考图加文字说明，不代表采用整图全部元素。
- 例如圈出参考图的袖口，关联到底稿的袖口标注，说明“借鉴褶皱结构，保持原袖口宽度”。参考图圈选指明灵感来源，底稿圈选指明修改目标，两者不能混淆。

### 4.2 圈选与文字标注

- 圈选工具范围（已确认）：第一版支持自由圈选，以及圈选的移动、重画和删除；暂不新增钢笔路径或像素级蒙版精修。复用现有画板工具基础进行适配，不另建一套绘画工具，也不据此删除现有画板能力。
- 圈选重叠规则（已确认）：允许多个圈选区域重叠，重叠本身不阻止提交或触发额外确认；若要求冲突，例如同一处同时要求收窄和加宽，则暂停生成并请设计师澄清，不按标注先后顺序擅自取舍。其他既定确认条件仍然适用。
- 全局修改要求（已确认）：允许直接填写“整体更宽松”“衣身比例拉长”等全局文字要求，无需圈选整件衣服，可与本轮局部标注一起提交。明确更新旧要求时按增量更新处理；同轮全局与局部要求存在实质矛盾或意图含糊时先澄清，不因“全局”而自动覆盖其他要求；未要求改变的设计仍须保持。无圈选不代表允许任意改动。
- 圈选与文字成对关联，多条标注采用稳定编号，便于检查对应关系。
- 多标注执行规则（已确认）：同一轮提交的标注统一处理，每张候选均须响应全部修改要求；要求冲突时先澄清。部分修改不满意时，沿用“以此候选继续修改”的逐轮修订方式。
- 标注绑定具体线稿版本，不能在采用新版本后自动沿用旧坐标。
- 圈选、编号和说明与干净线稿分开保存，最终输出不应包含标注痕迹。
- 标注颜色应与黑白灰面料表达明显区分。
- 圈选表示修改意图的范围，不直接等同于严格裁切的蒙版。缩短衣长等操作可能需要同时调整下摆与两侧轮廓衔接。
- 根据修改要求确定合理影响范围，并尽量保持其余结构；不能仅凭提示词就宣称区域外完全不变。
- 圈外联动规则（已确认）：为完成指定修改而进行的小范围线条衔接可以自动处理；涉及圈外肩线、领口、袖窿、衣身比例等结构变化时，先标出预计影响区域并说明原因，由设计师确认后生成。
- 例如只圈袖子却要求“改成插肩袖”，应提示还需调整肩线与袖窿，并取得此次结构联动的确认。该确认仅覆盖所展示的联动范围，不代表允许任意修改圈外设计。

### 4.3 候选与版本采用

- 候选数量规则（已确认）：初次融合与常规逐轮局部修订默认生成 2 张候选图，允许切换为 1 张；误改修复重新生成时例外，默认补 1 张、可选 2 张。第一版仅提供 1 张、2 张两个选项，不开放更多数量。数量指本次请求的新候选总数，不按标注数量倍增，也不包含已保留的候选。
- 下游生成数量（已确认）：基础效果图与颜色纹理阶段采用相同数量规则，常规生成默认 2 张、可选 1 张；因误改而修复生成时默认补 1 张、可选 2 张，保留已有合格结果。数量按本次请求计算，不因区域数量倍增；本决定不自动沿用线稿初次融合的差异探索策略，也不代表已验证下游模型的批量生成能力。
- 下游部分失败处理（已确认）：基础效果图或颜色纹理阶段仅部分结果生成成功时，保留成功图，不因同轮其他项失败而删除或覆盖。失败项由设计师手动补生成，不自动重试，也不重跑已成功图片。成功图与补生成结果均须遵循对应阶段的检查、确认或采用规则，保留或生成成功不等于自动通过。
- 失败补生成的输入一致性（已确认）：失败项补生成固定使用原任务提交时的输入版本与要求，不读取之后尚未提交的编辑，也不替换为后来选定的图片、材料或配色要求。若设计师修改了要求并希望执行修改后的内容，应发起新一轮生成，不能标记为原失败项重试。复用原输入不绕过当前有效的确认、拦截与单任务门槛；此规则针对执行失败的补生成，不等同于为修复设计误改而增加保持约束的新请求。
- 下游未知结果恢复（已确认）：请求超时且尚不清楚供应商是否完成时，标记“结果待确认”，先查询并恢复原任务，不立即补生成或把超时视为失败。恢复成功则保留原结果；确认失败后才按手动补生成规则处理。查询仍无法确定时保持待确认，不自动发起重复任务；供应商查询能力与长期无法恢复时的处理需验证或另行明确。
- 下游候选差异规则（已确认）：基础效果图与颜色纹理阶段的两张候选严格执行各自本轮同一组要求，仅作为同一要求下的不同生成结果供比较；不为制造差异而擅自改变结构、材料特性或指定配色。基础效果图仍遵循中性灰阶及不控制颜色纹理的阶段边界；两张无需像素一致，也不以视觉差异明显作为验收目标。
- 默认数量是产品需求，不代表模型质量、实际成功返回数量或底层调用方式已经验证。
- 候选差异规则（已确认）：初次融合的两张候选可在尚未确定的设计细节上提供适度差异，均须遵循明确的设计要求与保持要求；局部修订的两张候选严格遵循同一组修改要求，不为制造差异而额外改动已认可的结构。

| 动作 | 产品含义 |
| --- | --- |
| 生成候选 | 基于当前底稿和本轮要求生成新版本，不替换当前采用版本 |
| 以此候选继续修改 | 将候选作为本轮修订底稿，保留原先采用版本，不视为采用或定稿 |
| 采用此版 | 将选中的候选明确设为当前采用版本，并作为后续修改的默认底稿 |
| 确认线稿定稿 | 确认该版本的廓形、比例、结构、关键细节及黑白灰拼接分区，不要求确定实际面料 |
| 进入效果图节点 | 线稿定稿后即可进入，在节点内提供对应区域的实际材料，作为生成效果图的输入；进入节点不等于立即生成 |

- 未采用的候选不得自动替换当前采用版本；设计师可以主动选择候选作为修订底稿。
- 非预期修改拦截（已确认）：候选线稿若改变本轮未要求修改且未获允许联动的部位，必须阻止采用，不能仅提示后允许直接采用，也不能直接将该候选定稿或送入效果图。保留原采用版本及候选，供查看和对比。此前允许的小范围线条衔接及已确认范围内的结构联动不属于未经允许的修改。
- 非像素一致性要求（已确认）：未修改部位不要求与底稿像素完全一致，不能仅因存在像素差异就判定误改或拦截；这不放宽对未经允许的设计变化的拦截。具体设计差异与可接受绘制差异的判别口径、阈值仍需通过设计师案例验证，不能以像素相似度替代设计判断。
- 逐张拦截规则（已确认）：同轮候选分别检查、分别决定是否拦截。误改或待复核的候选暂停采用，不阻塞同轮另一张已通过检查的候选；后者仍可正常采用，但不因此自动定稿。解除某张候选的拦截不会改变其他候选的检查状态。
- 无法判定时的复核规则（已确认）：系统无法确定某部位是否被误改时，暂停采用，并展示本轮底稿与候选的对应区域供设计师复核；确认没有未经允许的变化后才解除该项拦截，确认误改或尚未确认则继续阻止采用。待复核候选也不能直接定稿或进入效果图。
- 确认误改后的重新生成（已确认）：回到产生该候选的本轮底稿，保留本轮修改要求，并补充对误改部位的保持约束，明确以底稿中该部位的原有设计为准；由设计师手动重新生成，不自动重试，也不默认沿用已误改候选作为新底稿。
- 误改修复数量（已确认）：默认仅补生成 1 张，允许选择 2 张；保留已有合格候选，不重新生成整轮。新候选仍须逐张检查，不自动解除原误改候选的拦截。
- 上述为产品验收要求，不代表已具备可靠的自动检测能力；检测口径、误报复核的具体交互及重新生成后的修复效果仍需验证。
- 部分修改满意时，支持“以此候选继续修改”。例如本轮要求修改袖口与衣长，结果袖口满意但衣长过短，可基于该候选重新标注衣长，要求保留满意的袖口；原先采用版本仍保留，直到设计师明确采用新结果。若属于未要求修改部位的未经允许变化，则默认走上述回到本轮底稿重新生成的路径，不与要求范围内效果不满意混淆。
- 第一版不提供两个版本之间的自动局部拼合，以避免服装结构衔接及面料灰度不一致。
- 旧版本及其标注应可回看，方便比较和追溯设计变化。
- 对比方式选择（已确认）：第一版提供“并排对比”和“叠加滑杆对比”，由设计师自行选择模式及参与对比的底稿或候选，不强制固定为“底稿＋单张候选”并排。首次展示方式另行确定；本次决定不视为已确认同步缩放、同步移动或自动定位等具体交互。
- 历史保留规则（已确认）：第一版不自动清理旧候选和历史版本，保留候选、对应要求与检查结果以便回看追溯；历史默认折叠展示，可展开查看，不以折叠替代或削弱查看、比较和继续处理能力。删除与容量规则另行确定，本决定不代表承诺无限存储。
- 生成失败或结果未知时，保留当前版本和本轮标注，提供恢复或重试路径。
- 部分失败规则（已确认）：两张候选仅一张生成成功时，保留成功图并允许立即采用或以此继续修改；另一张明确显示失败，由设计师决定是否补生成失败的候选，不自动重跑两张。
- 结果未知时先查询与恢复，不直接视为失败或自动重新生成，以避免重复生成和计费；具体恢复能力与状态判定需结合生成服务验证。
- 定稿后可以继续探索新版本，已有效果图仍关联其原始定稿版本。
- 新线稿版本需要重新确认，不能继承旧版的定稿状态。
- 逐轮继承规则：以选定图像作为本轮的当前状态，只执行本轮新提交的修改；整体设计要求和明确的保持要求继续有效，设计师调整意图时再更新。
- 生成期间编辑规则（已确认）：允许继续编辑标注，但运行中的任务始终使用提交时的底稿和要求；提交后的编辑作为尚未提交的修改保留，供下一次生成使用，并明确提示“当前修改尚未提交”。结果与非预期修改检查均以该任务实际提交的底稿及要求为依据，不以之后编辑的要求追溯解释结果；结果返回不覆盖未提交修改，后续提交不自动发起。
- 采用候选时的未提交标注（已确认）：若原底稿仍有未提交修改，采用新候选时提示其存在，并将这些标注保留在原底稿上，不自动迁移到新图，也不因采用操作而丢弃。设计师可返回原底稿继续修改，或在新候选上重新圈选；返回原底稿作为修订起点不自动撤销已采用的新版本。
- 修改草稿保存与恢复（已确认）：未提交标注自动保存为对应底稿的修改草稿，关闭工作区或刷新后重新打开时恢复已保存的圈选与文字，但不自动提交生成。保存失败时明确提示，不能显示为已保存，也不能承诺恢复尚未成功保存的最新编辑。草稿属于设计内容，其持久化须遵循项目文档边界；工作区开关等临时界面状态仍不进入业务文档。
- 单任务规则（已确认）：第一版同一工作区一次只运行一个生成任务；当前任务未结束时允许继续编辑，但不允许再次提交生成，也不自动排队。当前任务结束后，由设计师手动提交下一次生成。一次任务请求两张候选不视为两次工作区任务；本规则不扩展为全产品或整个账户的并发限制。
- 旧标注保留在历史中，不自动重放。例如上一轮“袖口收窄”已达到预期，下一轮仅修改衣长时，不应再次执行收窄袖口。
- 未完成的旧要求可由设计师主动选取，在新底稿上重新标注后继续处理；不得静默复用旧圈选坐标。新指令明确调整旧要求时直接更新对应项；只有意图含糊或仍存在无法确定意图的矛盾时，才先澄清再生成。

### 4.4 黑白灰与面料分区

- 线稿阶段仅使用黑白灰表达线稿结构、拼接及面料分区，不考虑实际面料，不建立实际配色方案；灰度不代表最终颜色或某种材质。
- 线稿阶段维护黑白灰区域与拼接分区的含义；进入“草图→效果图”节点后，再提供区域对应的实际材料，不能预设“浅灰＝羊毛”等固定映射。
- 实际材料说明方式：在“草图→效果图”节点中沿用圈选＋文字及可编辑清单，提供各区域的实际材料并核对对应关系，作为生成输入；不要求精确描边，不将这一步前置到线稿定稿或进入节点之前。
- 面料图片输入（已确认）：效果图节点支持上传面料图片，配合文字说明并关联到指定区域；也允许仅用文字描述，不强制上传图片。面料图片用于对应区域的材料表达，与线稿阶段用于借鉴款式结构的意向参考图区分。面料图片的数量限制与具体处理能力需单独验证，不直接沿用线稿融合的参考图上限。
- 基础效果图的材料边界（最新确认）：当前节点的面料图片与说明仅用于表达对应区域材料的厚薄、软硬、垂坠等特性，不以图片中的颜色或纹理作为本阶段应复现的目标，也不提供本阶段的颜色、纹理控制。颜色与纹理交给后续“面料配色替换”节点；从图片中分离这些信息的能力需要实际案例验证，不宣称模型已能可靠做到。
- 材料特性解释优先级（已确认）：在基础效果图阶段，材料图片与文字对厚薄、软硬、垂坠等特性的表达不一致时，以设计师明确的文字要求为准。例如图片看起来偏硬，但明确要求“柔软、垂坠”，则以该文字要求为生成依据；无法判断或意图不清时请设计师补充，不将模型从图片推测的特性自动视为已确认要求。本规则不允许改变未经授权的廓形与结构。
- 基础效果图呈现（已确认）：统一采用中性灰阶，以光影表现立体感及材料厚薄、软硬、垂坠等特性，不带入面料图片的颜色和纹理；线稿中用于区分拼接区域的黑白灰不等于基础效果图的最终配色要求。分区对应关系仍须保留，不能因改用灰阶光影而丢失拼接结构。
- 基础效果图展示形态（已确认）：默认采用无人物的服装立体展示，突出廓形、结构与垂坠，不默认引入模特或模特姿势。模特上身作为后续可选步骤，其具体范围与交互另行确定，不作为本阶段必经步骤。
- 跨视图复用面料说明（已确认）：正背面使用相同面料时，设计师可主动从另一面复制面料说明，再核对当前视图的区域对应关系；复制不等于当前视图已完成面料确认，不直接沿用另一面的圈选坐标或确认状态。两面说明不自动同步，避免分区不同而被错误套用。
- 新版本面料复核（已确认）：线稿修改产生新版本后，保留旧版面料说明供复用，但须重新核对新版本的区域对应关系并确认，不直接继承旧版面料“已确认”状态；衣片或分割线变化时应据此修正对应关系。旧版说明与确认记录仍保留，不因新版本待确认而被改写。
- 同一灰度可能是手绘阴影或面料标识，不能仅凭灰度自动确定材质。
- 材料信息与线稿灰度分开表达；在效果图节点内核对实际材料与区域的对应关系，生成时沿用确认后的说明。
- 阶段边界（最新确认）：线稿定稿后即可进入“草图→效果图”节点，实际材料尚未提供不阻止进入；在节点内提供材料作为生成输入。此前“补齐面料才能进入效果图”的门槛已被替代。
- 定稿后材料与外观变更：基础效果图阶段调整材料特性，后续“面料配色替换”阶段控制颜色与纹理；不改变廓形和结构时无需重新确认线稿，只核对相应阶段更新的输入，不将颜色与纹理控制移回线稿或基础效果图阶段。

### 4.5 定稿与下游处理

- 基础效果图确认门槛（已确认）：在本新模板中，进入“面料配色替换”的颜色与纹理调整前，须由设计师确认选定基础效果图的廓形、结构和材料垂坠符合预期。生成成功不等于确认通过；未确认时可查看、对比及按既定规则修订，但不能进入该后续阶段。本确认与线稿定稿分别表达，不替代线稿定稿，也不扩展为其他模板或独立节点的全局门槛。
- 基础效果图确认的版本绑定（已确认）：确认绑定具体图片版本，重新生成的新图须重新由设计师确认，不能继承旧图的确认状态，即使两图使用同一线稿和材料要求。旧图及其确认记录、配色结果保留，并继续关联原版本，不因生成或确认新图而改绑。
- 基础效果图确认撤回（已确认）：允许撤回具体基础效果图版本的确认；撤回后阻止基于该图发起新的颜色纹理生成，重新确认后方可恢复，其他既定检查规则仍适用。已有结果保留，已提交任务继续完成并保留结果，任务返回不得自动恢复该图的确认状态。
- 基础效果图材料修订（已确认）：廓形与结构正确、仅材料表现不满意时，留在基础效果图阶段修改厚薄、软硬、垂坠等说明并重新生成，无需返回线稿阶段或重新确认原线稿。新生成的基础效果图仍须重新确认；只有需要改变廓形或结构时才回到线稿修订与定稿。材料修订不授权模型意外改变已确认结构。
- 材料修订的输入关系（已确认）：以设计师当前选定的基础效果图为修改底图，保留其对应定稿线稿作为结构依据，仅调整指定区域的材料表现，保持其他已满意部分；不默认每次从线稿重新生成整件效果。选择某图作为修订底图不等同于确认该图，新结果仍须检查与重新确认。效果图与线稿的输入角色、顺序及模型保持能力需验证。
- 材料局部修订交互（已确认）：复用现有画板的“圈选＋文字”，在选定基础效果图上圈定部位并填写材料调整要求，例如“衣身更柔软、更垂坠，袖口保持不变”。标注绑定该基础效果图版本，不直接套用线稿或其他效果图的坐标；圈选表达修改意图，不等于精确像素蒙版。标注与干净效果图分开保存，不另建一套编辑工具。
- 材料局部修订检查（已确认）：逐张检查结果是否意外改变未指定区域。确认误改时阻止确认该基础效果图，也不能据此进入颜色纹理阶段；无法判定时暂停确认并由设计师对比复核，确认无未经允许的变化后才解除该项拦截。同轮通过检查的结果不受影响，但仍需设计师明确确认；被拦截结果保留查看与对比能力。检查针对设计及材料表现，不要求像素完全一致，自动检测能力仍待验证。
- 撤回与供应商任务边界：用户明确当前供应商接收任务后不可取消。撤回产品内的确认只影响后续新任务资格，不发起供应商取消、不将运行任务显示为已取消，也不承诺退款；结果应明确其来源基础效果图当前是否已撤回确认。
- 颜色与纹理的区域输入（已确认）：在“面料配色替换”节点复用已有分区，由设计师选择区域后提供颜色要求、纹理图片或文字说明；输入须与目标区域明确关联，未指定区域保持不变，不改变已确认的廓形与结构。复用分区指复用其对应含义，不代表将线稿圈选坐标未经核对直接套用到效果图；具体区域映射与编辑交互需验证。
- 颜色与纹理调整的材料保持（已确认）：仅调整颜色或纹理时，必须保留基础效果图中已确认的厚薄感、软硬表现、褶皱和垂坠，不能因更换纹理而将柔软面料变为硬挺效果。若设计师希望改变这些材料特性，应回到基础效果图阶段调整并重新确认，再进入颜色与纹理阶段；若同时涉及廓形或结构变化，仍须遵守线稿修订与重新定稿规则。
- 颜色与纹理结果拦截（已确认）：结果意外改变结构或已确认的垂坠等材料特性时，逐张阻止采用；无法判定时暂停采用，由设计师对比复核，确认无未经允许的变化后才能解除该项拦截，确认误改则继续阻止。同轮其他通过检查的结果仍可正常采用，不因一张异常阻塞整轮；被拦截结果仍可查看与对比，不能直接作为已通过结果继续下游处理。检测能力须单独验证，不以像素完全一致为标准，也不将未检出等同于没有变化。
- 颜色与纹理逐轮底图（已确认）：在同一基础效果图版本内连续调整时，默认基于该版本对应的当前已采用颜色与纹理结果继续；该基础图尚无已采用结果时，使用该已确认基础效果图。本轮仅更新指定区域，保留未指定区域及已满意的配色，不每次重置到基础效果图。仅生成或查看新候选不自动替换当前已采用结果，被拦截候选不因该规则成为默认底图，也不跨基础图混用已采用结果。
- 新基础图的配色起点（已确认）：切换到新的已确认基础效果图且不选择复用旧要求时，以新基础图重新开始配色，不自动带入旧基础图的配色结果或要求。旧配色仍留在历史中；此规则不删除旧记录，也不重置新图本身已确认的结构、材料特性及分区。
- 基础效果图更新后的历史保留（已确认）：重新生成并确认基础效果图后，保留此前颜色与纹理结果及其对应要求、原始来源关系，不覆盖或删除。保留不等于自动迁移到新基础图。
- 跨基础图复用要求（已确认）：设计师可主动将旧配色要求复用到新的已确认基础效果图，先核对新图的区域对应关系，再以新基础图及核对后的要求重新生成。复用的是要求，不是把旧结果覆盖到新基础图；不自动沿用旧圈选坐标、旧结果采用状态或检查结论，新结果仍须检查与明确采用。
- 颜色与纹理输入优先级（已确认）：在“面料配色替换”阶段，明确的文字颜色要求优先于纹理图片中的颜色，图片提供纹理特征。例如上传蓝色格纹并要求改为棕色时，以棕色为颜色目标并保留格纹特征，不因图片为蓝色而覆盖文字要求。描述含糊时先澄清，不擅自推断未明确的配色关系；该规则不将颜色或纹理控制前置到基础效果图阶段。
- 各视图独立进入效果图：正面或背面的具体线稿版本定稿后，即可独立进入效果图节点，再提供该视图各区域材料，无需等待另一面；一面的操作不改变另一面的状态，工作区单任务规则不变。
- 上传线稿直接定稿：已满意的上传线稿可由设计师确认具体版本定稿，跳过 AI 优化后直接进入效果图节点，再提供材料；上传不自动定稿，也不解除被拦截候选的检查状态。
- 定稿撤回规则：可撤回具体版本的定稿状态，保留线稿、标注和已有结果；撤回后不得以该版发起新的效果图生成。重新定稿后可恢复，并在效果图节点内完成生成所需材料输入。
- 撤回时的运行中任务（已确认）：已提交的效果图任务继续执行，返回结果保留，并在来源线稿仍处于撤回状态时注明“来源线稿已撤回定稿”；结果返回不得自动恢复线稿定稿状态。撤回仅阻止新的生成，不等同于取消已提交调用，也不承诺退还费用。
- 线稿定稿检查围绕廓形、比例、结构、关键细节及黑白灰拼接分区展开，不包含实际面料选定；实际材料在效果图节点内提供。
- 由设计师判断是否达到自己的预期，不强制每轮填写精确百分比分数。
- 系统可辅助提示未解决问题及前后差异，不以模型分数替代人工确认。
- 新模板只允许已定稿的具体线稿版本进入效果图节点，不以实际材料是否已提供作为进入门槛；材料在节点内作为生成输入。其他模板和独立节点的现有规则不变。
- AI 改款若改变已确认的廓形、比例或结构，应重新经过线稿确认；具体回流交互待设计验证。
- 效果图结构偏离规则（已确认）：生成效果图时若意外改变领口、衣长等已定稿结构，先视为效果图偏离定稿，保留原定稿线稿及其状态，由设计师选择是否重新生成，不自动采用意外变化。只有设计师主动认可新结构并希望沿用时，才进入线稿修订与重新定稿流程；对效果图中新结构的认可不等同于新线稿已定稿。
- 新结构回流方式（已确认）：希望沿用效果图中的新结构时，以原定稿线稿为修订底稿，将效果图作为参考，圈出并说明希望沿用的变化；仅借鉴指定变化，保留其他未要求修改的设计。生成候选线稿后重新确认，不将效果图直接替换为定稿线稿。例如只借鉴新领口，保留原衣长和袖型。

### 4.6 设计资料导出

- 导出范围（已确认）：保留单图下载，并支持设计师选择导出定稿线稿、已确认基础效果图、已采用颜色纹理结果及区域材料说明，组成一套设计资料。
- 按视图导出（已确认）：允许只选择正面或背面，导出该视图已完成的内容，不要求另一面或整套流程全部完成。PDF 明确列出本次包含的视图与阶段内容，不将单面或部分阶段资料描述为完整正背面资料；不为补齐导出而自动生成、确认或填充缺失内容。
- 导出需区分正面与背面，并保持所选结果与来源版本及材料说明的对应关系，不将不同基础图的结果或说明混为同一版本。
- 默认不包含失败或被拦截的候选；导出不改变采用、定稿或检查状态，不将未通过内容自动视为正式结果。此处不额外限制已有历史结果查看或单图下载能力。
- 导出格式（已确认）：整套资料以 ZIP 打包，包含所选结果的原尺寸图片及一份 PDF 设计说明。PDF 列出正背面、版本和区域材料对应关系，单独展示区域标记；独立图片保留干净版本，不带编辑圈线。PDF 用于审阅、交接与归档，不替代独立图片，不要求另行输出 Word。
- 命名规则、PDF 具体版式及原尺寸图片的文件格式待设计确认；不承诺超出源图实际分辨率，也不表示导出能力已经实现。

## 5. 工作区布局方向

沿用“草图线稿优化”节点作为入口，在节点内展示选定线稿并提供打开工作区的操作。不要因每轮修改自动增加一组画布节点。

- 中间：大幅线稿，支持圈选标注。
- 右侧：编号修改清单、文字要求和关联参考图。
- 底部：版本浏览与前后对比入口。
- 主要动作：按标注修改、采用此版、确认线稿定稿、进入效果图节点；实际材料的提供与核对放在效果图节点内。

以上为布局方向，尚未确定具体尺寸、控件细节及最终交互稿。实现须沿用本地 shadcn 通用控件、现有主题体系，并保持键盘操作、可见焦点和焦点恢复。

## 6. 第一版范围与后续探索

### 第一版优先验证

- 草图与意向参考图分别输入，并明确借鉴内容。
- 生成黑白灰线稿候选。
- 在选定线稿上圈选并填写修改要求。
- 标注可编辑、可删除、可关联参考图。
- 支持可选的参考图局部圈选及其与底稿修改标注的关联，也支持整张参考图配文字说明。
- 生成候选与采用版本分离，支持前后对比。
- 支持以尚未采用的候选继续修订，保留原先采用版本；不提供跨版本自动局部拼合。
- 定稿确认绑定具体版本，向效果图节点传递该版黑白灰线稿与拼接分区信息；实际材料在效果图节点内提供。

### 尚待确定的事项

- 整套资料已确定以 ZIP 打包原尺寸图片和 PDF 设计说明；命名规则、PDF 具体版式及图片文件格式待设计确认。保留单图下载，可选择导出各阶段正式结果与材料说明。
- 下游两个阶段部分失败时保留成功图、失败项手动补生成；未知结果先查询恢复原任务、不立即补生成的规则已确定。具体入口、供应商查询能力及长期无法恢复时的处理仍待明确或验证。
- 基础效果图更新后保留旧配色结果与要求，允许主动复用旧要求、核对区域后基于新图重新生成；不选择复用时从新基础图重新配色，不自动迁移。区域核对的具体交互仍待设计验证。
- 仅上传纹理图片、未填写颜色要求时的颜色来源尚未确认；“沿用图片颜色并明确展示来源”仅为建议，不作为已确认规则。
- 材料特性已确定以设计师明确文字为准，不确定时先澄清；图片特性识别与澄清触发的可靠性仍需案例验证。
- 同图正背面整张上传后圈定并标记视图，分别修改和确认、不自动联动；各面定稿后独立进入效果图节点，再提供对应材料。具体视图提取与展示方式待验证。
- 每轮参考图上限已确定为 3 张（不含底稿），第一版支持可选的参考图局部圈选；具体圈选及关联交互待设计，模型对底稿与多参考图的承载能力待验证。
- 三个阶段的数量与候选差异规则均已确定：常规默认 2 张、可选 1 张，误改修复默认补 1 张、可选 2 张；下游两张执行同一组要求，不主动制造设计差异。对比提供并排与叠加滑杆两种方式，由设计师选择，首次展示方式待明确；成本及各阶段实际生成、未知结果恢复能力仍需验证。
- 修改摘要已确定为可查看、非逐轮强制确认；冲突、借鉴范围实质歧义及圈外结构联动需先确认，具体展示入口与判别能力待设计验证。
- 圈选已确定复用现有画板，支持自由圈选、移动、重画和删除；区域可重叠，重叠本身不拦截，要求冲突时先澄清。具体交互、冲突识别、小范围线条衔接与结构变化的判别、预计影响区域的识别及展示方式仍需案例验证。
- 未经允许的部位发生变化必须阻止采用；无法判定时暂停采用并由设计师对比复核，确认误改后回到本轮底稿手动重新生成。检测口径与能力、误报复核的具体交互及修复效果待验证，不能将未检出等同于没有变化。
- 效果图节点内的材料说明支持面料图片＋文字或仅文字，并关联区域；图片数量限制、输入处理能力及具体区域对应交互待明确或验证。撤回定稿的状态展示与异步一致性仍需验证。
- 基础效果图已确定采用中性灰阶光影；如何表达材料厚薄、软硬和垂坠而不带入参考图片颜色与纹理，需验证模型能力。后续颜色与纹理采用已有分区＋图片／文字输入，具体区域映射与编辑交互待设计验证。
- 历史已确定第一版不自动清理、默认折叠展示；删除与容量规则待后续确定。
- 效果图新结构回流已确定采用原定稿线稿作底稿、效果图作参考并指定借鉴变化；具体入口、关联与操作交互待设计验证。
- 98% 目标的案例评价口径，不预设为可自动计算的质量分。

## 7. 验证与验收

### 行为验收

1. 一张草图与多张参考图的角色、借鉴要求能够明确关联。
2. 多个圈选的编号、位置和文字一一对应；编辑或删除不会串改其他标注。
3. 初次融合与常规局部修订默认请求 2 张候选，切换为 1 张后仅请求 1 张，第一版不提供其他数量选项；误改修复的数量例外按验收项 23 验证。生成候选不会覆盖当前采用版本，拒绝候选后仍能继续修改原版；选择“以此候选继续修改”只切换修订底稿，不改变采用或定稿状态。
4. 采用新版本后，旧标注可追溯但不会误套到新图。
5. 最终线稿保持干净的黑白灰表达，不带圈线、编号和修改说明。
6. 未定稿版本不能进入效果图节点，新线稿版本须重新定稿；已定稿版本即使未提供实际材料，也可进入节点，再提供材料作为生成输入。仅改变材料或颜色、不改变结构时无需重新定稿线稿。
7. 生成失败、结果未知、切换项目及刷新后，版本和运行结果的归属仍正确。
8. 在 1024、1280、1440px 桌面宽度验证标注、清单和版本对比可用性。
9. 圈外结构联动需先展示预计影响区域与原因，确认前不得执行该次结构修改；小范围线条衔接无需额外确认。使用插肩袖改动等案例验证影响范围判断，不能仅验证确认按钮存在。
10. 初次融合的候选差异仅发生在未确定细节上；局部修订的两张候选遵循同一组修改要求。结合设计师案例检查是否擅自改变已认可结构，不能将两张图视觉差异明显作为单独的通过标准。
11. 同一轮提交领口、袖口、下摆三条标注时，默认请求 2 张候选而非 6 张，每张候选的生成要求均包含全部三条标注；存在冲突时先澄清再生成。实际是否完成全部修改另由设计师评审，不以请求包含标注代替效果验收。
12. 两张候选中一张成功、一张失败时，成功图仍可采用或继续修改，失败项清晰标识，未经设计师操作不补生成；主动补生成不重跑成功项。结果未知时先查询恢复，不自动发起重复生成。
13. 参考图局部圈选可关联到底稿修改标注，明确区分借鉴来源与修改目标；以袖口褶皱借鉴案例验证关联及文字要求。未圈选参考图时仍可使用整图配文字说明，不强制补画圈选，也不默认复制未指定元素。
14. 每轮最多使用 3 张参考图，底稿不占参考图名额；选择少于 3 张不阻止生成，局部修订允许不带参考图。尝试加入第 4 张时明确提示上限，不静默丢弃或替换已选参考图。
15. 线稿阶段仅表达黑白灰结构与拼接分区，不要求填写羊毛、罗纹等实际材料；进入效果图节点后，可通过圈选＋文字提供材料并核对清单，不由灰度直接推断材质。
16. 以效果图意外改变领口或衣长的案例验证：原定稿线稿及其状态不被覆盖或撤销，可由设计师选择重新生成；只有明确选择沿用新结构时才进入线稿修订与重新定稿，不自动将效果图变化视为已确认的线稿设计。自动识别偏离的能力另行验证。
17. 沿用效果图新领口时，修订底稿为原定稿线稿，效果图角色为参考，生成要求仅借鉴指定领口变化并保持原衣长和袖型；候选线稿须重新确认定稿，不直接将效果图或未经确认的候选作为新定稿。
18. 清晰且不涉及圈外结构联动的要求可直接生成，无需额外确认摘要；摘要仍可查看。要求冲突、借鉴范围存在实质歧义或涉及圈外结构联动时，确认或澄清前不发起生成；小范围线条衔接不触发额外确认。
19. 仅要求修改袖口却意外改变领口的候选必须阻止采用，不能直接定稿或进入效果图；原采用版本保留，候选仍可查看和对比。分别用小范围线条衔接、已确认结构联动和未经允许的改动验证边界；检测可靠性另以设计师案例验证，不能只检查按钮状态。
20. 系统无法确定某部位是否误改时，候选暂停采用且不能直接定稿或进入效果图；展示本轮底稿与候选对应区域。设计师确认无未经允许的变化后解除该项拦截；确认误改或尚未确认时保持拦截，不能仅因打开或关闭对比视图而放行。
21. 确认领口被误改后，重新生成的默认底稿为产生该候选的本轮底稿，而非误改候选；保留原修改要求，补充保持底稿领口设计的约束，未经设计师主动操作不发起重新生成。新候选仍须经过非预期修改检查，不因补充约束而自动判定修复成功。
22. 同轮候选 A 误改或待复核、候选 B 已通过检查时，仅拦截 A，B 仍可正常采用；复核或修复 A 不覆盖 B 的结果或改变其检查状态，采用 B 也不解除 A 的拦截。
23. 因误改而重新生成时，默认仅请求 1 张新候选，主动选择 2 张后才请求 2 张；已有合格候选保留且不重跑整轮。新候选逐张检查，原误改候选不会因补生成完成而自动解除拦截。
24. 未修改部位不以逐像素完全一致为通过条件；像素差异本身不足以认定误改。对存在绘制差异但设计未变、以及确有未经允许设计变化的案例分别评审；无法判定时仍按暂停采用与人工复核规则处理。
25. 提交“修改袖口”后，在生成期间新增“缩短衣长”：运行中的任务仍只按已提交的袖口要求执行和检查，新增衣长要求显示为未提交；结果返回后该编辑仍保留，不自动再次生成，也不将本次结果描述为已执行衣长修改。
26. 同一工作区已有运行中的生成任务时，再次提交或重复点击不会创建第二个任务，也不会排队；标注仍可编辑。当前任务结束后保留未提交修改，只有设计师手动提交才发起下一次生成；一次请求两张候选仍按一个任务处理。
27. 原底稿存在未提交标注时采用新候选，应提示尚有未提交修改，原标注及文字继续绑定原底稿，不丢失也不自动套用到新图；返回原底稿可继续编辑，且不改变当前采用版本。在新候选上继续相关修改需重新圈选。
28. 未提交标注保存成功后，关闭再打开工作区或刷新页面，能在对应底稿恢复圈选与文字且不触发生成；模拟保存失败时明确提示未保存，不误报成功。切换项目后，迟到的保存结果不得写入另一项目或底稿。
29. 多轮生成和采用新版本后，旧候选及历史版本不会被自动清理，对应要求与检查结果仍可追溯；历史默认折叠，展开后可查看并使用原有比较与继续处理入口，继续处理仍遵循误改拦截等既定规则。折叠状态不写入业务文档。
30. 撤回某版定稿后，该版线稿、标注及已有结果仍保留并可查看，但不能以该版发起新的效果图生成；重新确认定稿且其他进入条件满足后方可恢复。撤回或重新定稿不删除已有结果。
31. 效果图任务提交后撤回来源线稿的定稿状态，已提交任务继续执行且不因撤回自动重试；结果返回后仍保留，来源线稿仍未重新定稿时显示“来源线稿已撤回定稿”。返回结果不得恢复定稿状态，撤回期间不能发起新任务，界面不将撤回描述为取消调用或退款。
32. 第一版可在并排对比与叠加滑杆对比之间切换，并由设计师选择参与对比的底稿或候选，不被限制为固定的“底稿＋单张候选”组合；切换对比方式不改变采用、定稿或检查状态，对比界面状态仍为本地 UI 状态。
33. 两个圈选重叠但要求兼容时，不因重叠本身阻止提交或要求确认；同一处分别要求收窄与加宽时，澄清前不得生成，不以标注顺序自动覆盖要求。仍须遵守圈外结构联动等其他确认规则。
34. 仅填写全局修改要求时，无需圈选整件衣服即可提交；全局要求与局部标注同时存在时，候选生成要求包含两者。同轮同时要求“缩短衣长”与“衣长保持不变”且无法确定意图时先澄清；明确的新指令更新历史要求则按增量更新处理。未指定变化不因全局要求而获得任意修改许可。
35. 设计师直接填写的保持要求可跨轮延续；系统提出的“保持领口”等建议在未确认时不得作为已确认的跨轮约束，确认后才延续。未确认建议不构成任意修改该部位的许可，仍遵循未指定修改部分沿用底稿的规则。

36. 上传线稿可不经 AI 优化而人工确认定稿，并在尚未提供实际材料时进入效果图节点；上传不自动定稿，材料在节点内提供，不改变已有被拦截候选的状态。
37. 同一设计包含正面与背面时，分别编辑和确认；修改或确认正面不自动修改背面，也不使背面自动获得定稿状态。第一版不将多视图结构一致性描述为已自动保证。
38. 上传一张同时包含正面与背面的草稿时，不要求预先拆成两个文件；可圈定并标记两个视图，选择对应视图进行修改和确认，视图区分不得被误当作局部修改指令。
39. 正面已定稿、背面仍在修改时，正面可独立进入效果图节点，再提供实际材料；结果关联具体视图、线稿版本和提交时材料，不改变背面状态，也不绕过单任务规则。
40. 在效果图节点内主动复制另一面的材料说明后，须核对本视图区域并确认，不继承另一面的坐标或确认状态，也不自动同步。待核对状态影响材料输入是否可用于生成，不阻止已定稿线稿进入节点。
41. 线稿产生新版本后，旧材料说明保留供效果图节点内复用，需核对新版本区域并确认，不继承旧版确认状态；新线稿定稿后即可进入节点，无需先完成材料复核。旧版说明与记录不受影响。
42. 在效果图节点可上传面料图片、填写说明并关联指定区域，生成输入保留其区域对应关系；仅填写材料文字时不因缺少面料图片而被阻止。图片不被误作线稿结构参考，也不改变线稿定稿状态；实际材料还原效果需案例验证。
43. “草图→效果图”节点以厚薄、软硬、垂坠等特性为材料表达目标，不默认沿用面料图片颜色或纹理，也不在此阶段要求配置颜色或纹理；相关控制归于后续“面料配色替换”节点。用带明显颜色与纹理的参考图检验阶段隔离及结构保持，不能仅凭提示词或界面无控件宣称实现。
44. 基础效果图为中性灰阶，以光影表现立体感与材料特性，不带入上传面料的颜色和纹理；线稿灰度用于分区而非指定最终配色。对照定稿线稿检查拼接结构与区域对应关系是否保留，并由设计师评审材料特性表达，不以简单去色作为全部验收依据。
45. 默认生成无人物的服装立体基础效果图，不自动加入模特或改为模特上身展示；结合设计师案例检查廓形、结构和垂坠表达。无需完成模特上身步骤即可继续既定流程。
46. 新模板中，基础效果图生成成功但未经设计师确认时，不能进入颜色与纹理调整；设计师确认选定图的廓形、结构和材料垂坠后才允许进入。线稿已定稿不能自动代替基础效果图确认，确认基础效果图也不改变线稿版本的状态。
47. 在已确认的基础效果图上选择已有分区并提供颜色要求、纹理图片或文字说明时，生成输入与目标区域一一对应；以仅调整衣身、保留袖口的案例检查未指定区域及已确认廓形、结构是否保持。区域复用不得静默误套线稿坐标，实际生成效果须通过设计师案例验证。
48. 在颜色与纹理阶段上传蓝色格纹图片并明确要求棕色时，生成要求以棕色为目标并借鉴格纹特征；实际结果由设计师检查颜色与纹理表达。颜色描述含糊时先澄清，不以图片颜色静默覆盖明确文字，也不将该优先级用于基础效果图的材料特性输入。
49. 基础效果图阶段，材料图片看起来偏硬而文字明确要求“柔软、垂坠”时，生成依据采用文字要求，不以模型对图片的推测覆盖；无法判断或意图不清时先请求补充。实际材料特性表达与结构保持分别由设计师评审，生成输入正确不等于效果已达标。
50. 仅替换颜色或纹理时，对照已确认基础效果图检查厚薄感、软硬表现、褶皱和垂坠是否保持；柔软面料被意外改为硬挺效果不能视为符合要求。主动改变材料特性须回到基础效果图阶段调整并重新确认，不能绕过该确认直接继续配色；涉及廓形或结构变化时仍需回到线稿确认。
51. 同轮颜色与纹理结果 A 意外改变结构或垂坠、B 通过检查时，只阻止采用 A，B 仍可采用；A 无法判定时保持待复核，确认无未经允许的变化才解除该项拦截，确认误改则继续阻止。结果仍可查看对比，不得通过直接下游处理绕过采用拦截；检查可靠性须以实际案例验证。
52. 尚无已采用颜色与纹理结果时，以已确认基础效果图为默认输入；采用衣身配色结果后，下一轮仅修改袖口时默认使用该已采用结果，保留衣身配色及其他未指定区域，不重置为基础效果图。仅生成或查看其他候选不改变默认输入，实际结构与材料特性保持仍须检查。
53. 基础效果图重新生成并确认后，旧颜色与纹理结果及对应要求仍可回看，来源仍指向原基础图，不被覆盖、删除或静默改绑到新基础图。
54. 主动选择复用旧配色要求后，须核对新基础图的区域对应关系，再以新基础图及核对后的要求生成；不直接套用旧坐标、不将旧结果覆盖到新图，也不继承旧结果的采用状态或检查结论。未核对前不提交该次复用生成，新结果按既定规则检查与采用。
55. 旧基础图 A 已有采用的配色结果，切换到新的已确认基础图 B 且不选择复用时，以 B 为配色起点，不自动加载 A 的配色要求或使用 A 的结果作为生成输入；A 的历史仍可回看。B 后续有已采用配色结果后，沿用同一基础图内的逐轮调整规则。
56. 分别验证基础效果图与颜色纹理阶段：常规生成默认请求 2 张，切换后仅请求 1 张；误改修复默认请求 1 张，主动选择后可请求 2 张。多区域输入不放大数量，已有合格结果不被重跑或覆盖；数量选项通过不等于实际生成能力与质量已验证。
57. 基础效果图及颜色纹理阶段的两张候选使用同一组本轮要求，不额外添加使两张结构、材料特性或指定配色不同的指令；逐张检查结果是否遵循要求，不因两张视觉相似判定失败，也不因差异明显判定通过。
58. 基础效果图 A 已确认后重新生成 B，B 初始为未确认，不能继承 A 的状态或直接进入颜色纹理阶段；设计师确认 B 后才允许继续。A 的确认记录及其配色结果仍关联 A，不被新图生成或确认操作覆盖、删除或改绑。
59. 颜色纹理任务提交后撤回其来源基础效果图的确认，已提交任务继续且返回结果保留，不触发供应商取消，也不自动恢复来源图确认状态；撤回期间不能基于该图发起新任务。已有结果可查看，来源图仍处于撤回状态时明确标示，重新确认后才恢复新任务资格。
60. 基础效果图结构正确但材料过硬时，可在效果图阶段将材料说明调整为更柔软并重新生成，不强制返回线稿或撤销其定稿；新基础效果图须重新确认。若要求同时改变廓形或结构，则进入线稿修订路径，不以材料调整绕过线稿确认。
61. 选定基础效果图并仅要求衣身更柔软时，以该效果图作为修改底图、对应定稿线稿作为结构依据，生成要求保留未指定区域的材料表现及已确认结构；不得默认改成仅从线稿重新生成。选择底图不自动确认它，新结果仍需检查和人工确认，实际保持效果须案例验证。
62. 在基础效果图上使用现有画板圈选衣身并填写材料调整要求时，圈选、文字与当前图片版本明确关联；切换图片版本不静默复用坐标，生成输入不混入其他版本标注，输出效果图不带圈线或说明文字。结合案例验证指定材料变化及未指定区域保持。
63. 仅要求衣身更柔软却意外改变袖口材料表现的基础效果图，必须阻止确认及进入颜色纹理阶段；无法判定时保持待复核，确认无未经允许变化后才解除拦截。同轮合格结果仍可独立确认，打开对比或生成成功均不自动解除拦截，原图与结果仍可查看。
64. 基础效果图与颜色纹理阶段各生成两张、仅一张成功时，成功图仍保留，不因另一项失败被删除或覆盖；原检查和人工确认／采用门槛仍生效，不因部分成功而自动放行。
65. 下游两张结果中一张失败时，不自动创建重试任务；设计师选择补生成后仅补失败项，不重跑或覆盖成功图。补生成结果仍须按其阶段规则检查及确认／采用，不能因属于重试而跳过。
66. 模拟下游请求超时但供应商状态未知时，显示“结果待确认”并查询原任务，不以超时创建新的生成请求；查询成功后恢复原结果，确认失败后才允许按既定规则手动补生成。持续无法判定时保持待确认，不自动标记失败或重复生成。
67. 原任务部分失败后编辑了材料或配色要求，再选择失败项补生成时，仍使用原任务提交时的输入版本和要求，未提交编辑不被覆盖或混入；选择执行新要求则创建新一轮生成，不冒充原失败项重试。当前确认与拦截门槛仍有效，原成功结果不重跑。
68. 可选择导出定稿线稿、已确认基础效果图、已采用颜色纹理结果及区域材料说明，单图下载仍可用；导出资料区分正背面及来源版本，说明与所选结果相匹配，默认不包含失败或被拦截候选。导出不改变各阶段状态。
69. 整套导出得到可打开的 ZIP，包含所选结果的独立原尺寸图片及可阅读的 PDF 设计说明；图片尺寸与源结果一致且不带编辑圈线，PDF 中的正背面、版本、区域标记和材料说明与所选内容对应，不以 PDF 内嵌预览图替代独立图片。
70. 正面已有完成内容、背面尚未完成时，可仅选择正面导出 ZIP 与 PDF，背面未完成不阻止导出；PDF 明确本次包含的视图与阶段，包内不混入未选择视图，也不自动生成或确认缺失内容。仅选择背面的场景同样适用。
